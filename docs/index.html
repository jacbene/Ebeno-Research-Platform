Pourquoi la souveraineté ?

Vos données de recherche ne devraient pas traverser l'Atlantique. Toutes les briques critiques d'Ebeno sont auto-hébergeables.

☁️ Mode SaaS (Cloud)

  • Stockage : Cloudinary (US)
  • IA Texte : OpenAI / DeepSeek (US/CN)
  • IA Audio : Deepgram (US)
  • Emails : Brevo (FR)
  • Monitoring : Sentry (US)

🔒 Mode Self-Hosted (Souverain)

  • Stockage : MinIO (local)
  • IA Texte : Ollama (local)
  • IA Audio : Whisper Local (local)
  • Emails : SMTP local (local)
  • Monitoring : GlitchTip (local)

👉 En mode self-hosted, aucune donnée ne sort de votre infrastructure. Idéal pour les projets santé, sciences politiques, données sensibles.
